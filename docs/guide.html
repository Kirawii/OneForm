新手用户指引

五分钟上手

不需要安装软件，也不需要懂代码。推荐直接使用网页版。

照着做就可以

  1. 打开在线版

    点击页面上的“在线使用”。

  2. 填写自己的资料

    从“基本信息”开始，按左侧目录逐项填写。

  3. 点击复制按钮

    报名时找到对应字段，点击输入框旁边的复制按钮。

  4. 粘贴到学校系统

    回到学校报名页面，把内容粘贴到对应输入框。

  5. 导出一份备份

    点击“导出 JSON 备份”，把文件保存在自己的电脑里。

一定要记住

资料保存在当前浏览器。换浏览器、换电脑、清理浏览器数据或使用无痕模式时，原资料可能无法读取。请定期导出备份。

在线版和离线版

方式适合谁怎么用
在线版推荐大多数人点击“在线使用”
离线版希望断网使用下载后双击 HTML 文件

离线文件准备改名、移动位置或换电脑前，请先导出 JSON 备份。

隐私提醒

导出的 JSON 文件没有加密。不要上传到公开网盘、GitHub、群聊或论坛，也不要把身份证号、手机号、家庭信息和备份文件发给陌生人。

遇到问题

复制按钮没有反应

先确认输入框中已经有内容。如果浏览器询问剪贴板权限，请选择允许。

刷新后资料不见了

检查是否换了浏览器、移动了离线文件或使用了无痕模式。如果有 JSON 备份，点击“导入备份”恢复。

学校字段和页面不一样

先搜索最接近的字段，再按学校要求调整格式。最终以目标院校当年的官网通知为准。
