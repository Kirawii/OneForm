先填写自己的资料

按左侧目录填写，页面会自动保存。外语、科研、竞赛和奖励可随时增删，额外信息填在“自定义字段”中。

找到学校要求的字段，点击输入框旁边的复制按钮，再粘贴到报名系统。

定期导出备份

在“更多”中点击“下载备份”，把文件保存在自己的电脑里。更换浏览器或电脑时可以恢复。

常见问题

第一次使用时，最需要知道的几件事。

关闭页面后，资料还在吗？

通常还在。资料保存在当前浏览器中。换浏览器、换电脑、清理浏览器数据或使用无痕模式时，原资料可能无法读取。

资料会上传到网上吗？

项目本身不会主动上传填写内容。请只使用你信任的官网地址，不要使用来源不明的修改版。

备份文件安全吗？

导出的 JSON 文件是明文，任何拿到文件的人都可能读到内容。请保存在自己的设备中，不要公开分享。

竞赛或奖励太多，填不下怎么办？

在对应栏目点击“添加竞赛”或“添加奖励”即可增加条目。需要额外信息时，可添加自定义字段。每个输入框旁都有复制按钮。

能自动填学校系统吗？

目前需要自己复制粘贴。OneForm 不会读取学校系统、自动填表或替你提交申请。

手机可以使用吗？

可以打开和查看，但报名通常还要处理证明材料，建议使用电脑完成正式填报。

整理你的报名资料

先把资料整理清楚，真正报名时只需要查找、复制和核对。
