常见问题

第一次使用时，最需要知道的几件事。

关闭页面后，资料还在吗？

通常还在。资料保存在当前浏览器中。换浏览器、换电脑、清理浏览器数据或使用无痕模式时，原资料可能无法读取。

资料会上传到网上吗？

项目本身不会主动上传填写内容。请只使用你信任的官网地址，不要使用来源不明的修改版。

备份文件安全吗？

导出的 JSON 文件是明文，任何拿到文件的人都可能读到内容。请保存在自己的设备中，不要公开分享。

手机可以使用吗？

可以打开和查看，但报名通常还要处理证明材料，建议使用电脑完成正式填报。

准备好自己的报名底稿

先把资料整理清楚，真正报名时只需要查找、复制和核对。
